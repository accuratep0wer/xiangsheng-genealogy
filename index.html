    说明

    本站根据公开资料整理中国相声演员的师承谱系，时间范围从清末（张三禄、朱绍文“穷不怕”、阿彦涛、沈春和）到当代（德云社“云鹤九霄”、“筱”字辈等）。每位人物和每条关系都附有来源链接。

    辈分与字辈

    相声界通行把张三禄算作第一代，朱绍文、阿彦涛、沈春和为第二代，分为朱、阿、沈三派。第四代至第八代按“德、寿、宝、文、明”排字（也曾有“德、寿、立、仁、义”之说，较少使用）。第一至第三代、第九代及以后没有全行业统一的字辈；各门户自行排字，例如德云社郭德纲门下“云、鹤、九、霄”，再下一辈“筱”字；青曲社“海纳百川万象归春”。

    关系类型

    • 师徒：正式拜师（摆知）的师承，箭头由师父指向徒弟。
    • 代拉/引保代/口盟等：代拉师弟（代师收徒）、拜师时的引师、保师、代师，口盟弟子，义父子，以及早年学艺但不算正式师承等情况。
    • 亲缘：父子、兄弟、祖孙、舅甥、表亲等血缘关系。
    • 姻缘：夫妻、翁婿等婚姻关系。

    可信度

    确定：至少一个公开来源明确列出，图中用实线。存疑：来源本身标注存疑，不同来源说法冲突，师徒关系后来被解除，或只有网络转载、自媒体之类的弱来源，图中用较淡的虚线。可用「只显示确定」暂时隐去存疑关系。相声门户的师承本来就常有“改换门庭”、“代拉”、“清门”、“辈分自降”等复杂情况，请把本站当作索引，不要当作定论。

    方法

    1. 主干取自维基百科《相声演员师承关系》条目。该条目以中国相声网《师承关系表》（据阎笑儒1960年传殷文硕的《相声宗谱》誊写）为主，第九代以梨园论坛《相声师承关系——九代传人》为主。
    2. 逐一读取约190个相声演员维基条目里的“师承关系”信息框（从师、世代、辈分、徒弟）和“配偶/父母/儿女/亲属”栏目，再与正文中“之子”、“门婿”、“代拉”、“引保代”等表述互相印证，补充师徒和亲缘、姻缘关系。
    3. 德云社部分依据郭德纲条目引用的2016年《德云社家谱》（北京晨报），并参考网络整理文章补充“筱、昊、展、奉”等再传弟子；青曲社、孟鹤堂等依据公开报道补充。
    4. 同名人物：若师父不同、无法确认是否同一人，就分开收录并加注说明；繁简异体、条目消歧义造成的重复，在同一师父下按同名合并。
    5. 代数：优先采用谱系表的位置和个人条目里的“世代”，其余按师承逐代推定（标为“按师承推定”）。

    参考的同类项目与资料

    • jammyfu/xiangsheng-genealogy《相声家谱》（MIT 许可）：一个开源的水墨三维师承图谱。本站读取了它整理的 338 条带出处的师承边，用来交叉核对，并采用了其中的存疑标注、补充师承和来源链接（凡采用处都在关系的来源和备注里写明了出处）；没有复制它的代码。
    • 梨园百年琐记“师承谱图”（戏考）：根据《相声师承关系总表》整理的逐人展开式谱图，用虚线表示代拉师弟。本站的代拉、引保代关系分类参考了它的做法。
    • 维基百科《相声演员师承关系》（CC BY-SA 4.0）：本站师承的主干数据。
    • 百度百科《相声师承关系总表》和央视网转载天津日报“中国相声师承关系族谱”：早期几代的旧谱，用来核对不同说法（例如沈竹善、春长隆、冯昆治的师承归属），只作书目参考。
    • 新京报（2006）“中国相声门谱系”：介绍了马三立《京津相声演员谱系》和《中国相声史》师承表的来历，以及张三禄是否算始祖的争议。
    • 星空历史“相声师承关系总谱（横版世系图）”、invictusmuzi 的 Neo4j 相声师承图、中国相声网师承图谱专题：在展示方式上作了参考。

    局限

    • 收录以公开资料为限，大量基层、地方曲艺团和民间演员没有收录；当代各社团收徒更新很快，难免遗漏。
    • 原始谱系表本身被维基标注为“原创研究”，有些人名用字彼此不同。能核对为同一人的已经合并（贾仑／贾伦、刘德智／刘德治、两位张康）。侯一尘与谱系表上的侯少尘对不上，分开收录并加了注。
    • 图画出每一个至少有一条关系的人，小团体也画，不要求连上主谱系。只有一条关系都没有的人留在数据里、可以搜索，侧栏会写「没有任何关系」，三张图都不画。
    • 亲缘、姻缘只收录有来源可查的部分；亲属中不是相声演员的，只因关系需要列出（图中显示为灰色）。
    • 不收录任何私人联系方式。如果发现错误，请用页眉或人物侧栏的「提交修正」打开 GitHub 议题（需要 GitHub 账号，本站没有邮箱通道）。

      第三方组件

      图谱使用 Cytoscape.js（MIT 许可，已本地打包在 vendor/ 目录）。全网络有两套坐标，都由本站自己计算、不另引布局库：一套是预先算好的紧凑全图（NetworkX spring layout），另一套在此基础上把挤在一起的姓名推开。放大时在两套坐标之间平滑过渡，缩小自动回到全图；拖动时邻近门派已经疏开，不会被藏起来。聚焦某一人（地址 #graph/人物编号）时仍用环形谱系。人物与关系数据整理自维基百科等公开来源，维基百科内容采用 CC BY-SA 4.0 许可。
